# External comparison references

- Palm webOS, *User Interface*, O'Reilly preview (primary-era text):
  <https://api.pageplace.de/preview/DT0400.9781449391997_A23800502/preview-9781449391997_A23800502.pdf>
  (accessed 2026-09-23). The cited principles are direct interaction, minimal
  steps for common functions, visible frequent commands, consistency, and
  avoiding a modal control when a non-modal route works.
- webOS Open Source Edition, [UI guide](https://www.webosose.org/docs/guides/getting-started/webos-ose-ui-guide/)
  (accessed 2026-09-23). This is current webOS OSE documentation for the app
  bar and launchpad. It is used only as a comparison for persistent access to
  favorite/running applications; this handheld does not copy its television
  interaction model.

Neither source establishes behavior on the K230 hardware. Repository evidence
and the acceptance gates in this audit remain authoritative for that claim.
