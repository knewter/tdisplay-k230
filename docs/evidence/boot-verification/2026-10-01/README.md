# Coherent-shell physical boot verification, 2026-10-01

The matching current vendor-kernel candidate reaches serial/root and starts shell, seatd, Rust UI, PipeWire and WirePlumber, **but initial camera output appears dark after compositor startup**. It was not selected persistently. The original boot files and system profile are unchanged, normal boot restored visible Home, and the latest runtime system was reactivated on the working booted kernel. Visible navigation acceptance remains unresolved, with successful recovery; this is not a shipped persistent update.
