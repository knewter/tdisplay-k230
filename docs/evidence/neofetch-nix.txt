===== Host narrow build: RISC-V uarch parser =====
`nix build .#neofetch --option max-jobs 2 --option cores 8 --option substituters https://cache.nixos.org` rebuilt the package after applying `nix/patches/neofetch-riscv-uarch.patch` to pinned Neofetch 7.1.0. It produced `/nix/store/10bmbyyj6ljyjrjbg3l83gkpwr7lx8qa-neofetch-7.1.0`; `nix path-info -S` reports 71684640 bytes. This is a laptop build, not board proof. An isolated parser fixture appeared to pass, but did not validate the full installed script. The first physical run failed with a syntax error: the zero-context patch inserted the RISC-V arm after the default-case marker. That package is invalid and was not activated as the normal command; see `neofetch-riscv-board.txt`.

===== Corrected contextual patch and physical execution =====
The patch now includes the surrounding ia64/default-case context, and the
Nix install phase runs `bash -n neofetch` before producing the package.
`nix build .#neofetch --option max-jobs 1 --option cores 1 --option substituters https://cache.nixos.org`
succeeded, producing `/nix/store/j7m1v5k5m0h8b46m8krngrqfmxmsc023-neofetch-7.1.0`.
The installed script also passed a whole-file syntax check on the build host
and on the board. Actual physical execution via serial printed:
  CPU: T-Head C908 (RISC-V64) (1)
See `neofetch-riscv-corrected-board.txt`. The board exposes no measured CPU
frequency to this path, so none is appended. The original failing package
was imported for testing but never activated as the normal command.

The corrected package was then installed into the board's default Nix profile
(`/nix/var/nix/profiles/per-user/root/profile`, also reached through the
system's default profile link). Both root and the shell user resolve ordinary
`neofetch` to this package and print the corrected CPU name; see
`neofetch-riscv-profile.txt`. An attempted `hash -r` reported hashing disabled;
the subsequent explicit command lookup and executions verify the result.
The system closure itself remains the previously verified portrait image;
future image builds include the source fix through nix/neofetch.nix.
