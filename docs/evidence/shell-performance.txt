PSS is summed across the shell user's graphical/session processes and
proportionally accounts for shared pages. Individual process RSS values are
in the transcript; summing RSS would double-count shared pages. The cgroup
MemoryCurrent also accounts for memory charged to the service beyond the
process PSS, so the two values are not interchangeable. These are sequential
snapshots, not an atomic whole-system measurement or a peak-load benchmark.

CPU-side frame-work timing and the representative scrolling-terminal load
remain unmeasured. No FPS or compositor-throughput claim follows from these
memory numbers or from the sampled feature videos.
