Stage-1 splash port build (build-host evidence only)
====================================================

This record is source-build evidence only.  It does not say the splash has
been put on a card, flashed, or shown on the panel.

Source and build limits
-----------------------

The asset, U-Boot and stage-1 builds used the clean integration commit
`cc3c37c` (`Accept ImageMagick channel depth suffix`) with:

```
NIX_CONFIG='substituters = https://cache.nixos.org/' \
  nix build <attribute> --max-jobs 2 --cores 8 --print-build-logs
```

`bootSplashImage` built one derivation in 3 seconds. `uboot-k230` built one
derivation in 20 seconds. `stage1` built two packaging derivations in 3
seconds, reusing that U-Boot result.
