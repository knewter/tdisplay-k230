Set deliberately high. The capability taxonomy in
.skills/k230-spec-change/SKILL.md allows fifteen capabilities and the
tree above has nine, so ordinary growth must not turn the budget red.
A breach should mean something changed -- an evidence file the size of a
video, or a renderer that started doing real work -- not that the numbers
were always tight. A budget raised reflexively means nothing.
